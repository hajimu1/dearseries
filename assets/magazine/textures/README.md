# Magazine paper textures

Six textures selected from the user-provided paper and photocopy folders. sources.json records original paths and SHA-256 hashes. Originals are untouched. Copies preserve color and aspect ratio, resize the longest edge to at most 1800px, and encode JPEG quality 85 for offline loading. No generated texture or color normalization was used.

Update: copier-grain is no longer offered in the editor; newsprint replaces it. Rice paper, kraft wrinkles, white wrinkles and light copy are also added, sourced and resized using the same method.
