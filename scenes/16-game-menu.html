DEAR SERIES / 16 · MEMORY CARD

글자나 이미지를 클릭하면 재생을 멈추고 해당 편집 항목으로 이동합니다.

MEMORY CARD / EDITOR

기억을 불러오는 중.

메뉴 → 4슬롯 → 뒤로가기 → 메뉴의 반복입니다.

게임 메뉴 편집

메인 메뉴

메인 이미지를 화면 가득 배치합니다. 배경과 메인 이미지는 각각 교체할 수 있습니다.

네 개의 기억

선택한 슬롯의 미리보기 시점으로 이동합니다.

클릭 · 반복 효과

효과는 메인 메뉴에서만 보이며 로드 창에서는 숨겨집니다. 미리보기 위에서 ‘메뉴·효과 체험’을 선택한 뒤 화면을 클릭하면 효과 중심을 옮기고 재생합니다. 메뉴·슬롯을 누르면 해당 선택도 함께 적용합니다. 일시정지하면 효과도 멈추며 PNG·GIF·영상에 그대로 담깁니다. 화면에 포커스를 두고 방향키로 효과 위치를 움직이거나 Enter로 재생할 수도 있습니다.

화면과 시간

레트로 화면

낮은 해상도로 그린 화면을 확대합니다. 색상 단계는 RGB 채널별 단계이며, 색 번짐은 가로 방향으로 색을 퍼뜨립니다. 모든 효과는 PNG·GIF·영상에도 적용됩니다.

PNG는 현재 순간, GIF·무음 영상은 한 바퀴를 저장합니다. GIF는 완성 후 실제 15MB 기준으로 용량을 확인하고 축소할 수 있습니다.

실제 게임 저장 데이터가 아닌 애니메이션입니다. 편집 내용은 장면 이동 시 유지되며 새로고침하면 초기화됩니다.
