Dear Series 배포본

1. ZIP을 풀고 dear-series.html을 Chrome 또는 Edge에서 여세요.
2. 인터넷 연결 없이 01~05 테마를 편집하고 PNG, GIF, 영상을 저장할 수 있습니다.
3. 실행에 필요한 기본 이미지와 폰트는 HTML 안에 내장되어 있습니다. assets/와 fonts/는 원본 파일 보관용이며 HTML 옆에 없어도 실행됩니다.
4. 업로드하거나 수정한 내용은 열린 페이지에서 적용됩니다. HTML 편집본 저장 기능은 제공하지 않습니다.
